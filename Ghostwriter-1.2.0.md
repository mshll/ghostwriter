Suggestions in terminal coding agents, a way to run only in the apps you pick, and a menu bar icon that shows when Ghostwriter is off.

- **Terminal coding agents.** Suggestions show while you write a prompt for a coding agent, such as Claude Code, in Terminal or Orca. Shell commands get no suggestions, and nothing typed in a terminal is recorded. Turn it off in Settings > Apps.
- **Only the apps you choose.** Settings > Apps > Show suggestions in: pick "Only apps I choose", then add apps there or turn Ghostwriter on from the menu bar.
- **See when it is off.** The menu bar icon shows a slash while Ghostwriter is paused everywhere, and dims while you are in an app where it is off.

Requires macOS 26 or later on Apple silicon.
